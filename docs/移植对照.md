## 2. 行为差异（均为「补实现/修正」，不改既有口径）

1. **上传是真的会落盘**：C# `UploadHandler.Process` 全部注释，永远返回「未知错误」；
   `UeditorConfig.GetStringList` 也返回空数组（扩展名白名单恒为空，任何上传都会被拒）。
   Rust 侧按 UEditor 官方协议实现：校验扩展名 → 校验体积 → 路径格式化 → 落盘 → 返回
   `{state,url,title,original,type,size}`。
2. **抓取远程图片**：C# 的 `Crawler.Fetch` 内容被注释，只回 `state=null`；Rust 实现下载并
   落盘，且**只允许 http/https**（C# 注释里的 `IsExternalAddress` 校验在上游缺失，等于可 SSRF）。
3. **`{rand:n}` 位数**：C# `rand.Next(10^n, 10^(n+1))` 实际生成 n+1 位；Rust 按官方实现生成 n 位。
4. **文件名清洗**：C# 删除 `\ / : * ? " < > |`；Rust 用 `dhrust::io::sanitize_file_name`
   替换为 `_` 并把 `..` 折叠为 `__`，另加「落盘路径必须在根目录内」的二次校验。
5. **扩展名归一化**：`ueconfig.json` 的 `imageAllowFiles` 里有 `"webp"`（缺前导点），
   比较前统一补点并小写，避免漏判。
6. **后台持久化**：C# 直接写 `SiteInfo` / `DHSetting` / `SysConfig`；Rust 定义
   `AdminBackend`（`settings` / `save_settings` / `login`），由消费方接入自己的存储层。
7. **登录口令**：示例 `MemoryBackend` 用 `dhrust::sign::password`（与 C# `SaltPasswordProvider`
   字节级互通）存验；生产实现必须同样使用该模块，不要自写散列。

## 3. 视图：C# Razor → Razor 子集

`dhrust::razor` 只支持子集（见 DH.RustBase `Doc/Razor子集模板引擎架构.md` §3.2）：

| 支持 | 不支持（需改写） |
|---|---|
| `@expr`、`@(expr)`、`@@`、`@* *@` | `@using`、`@inject`、`@functions`、`@helper` |
| `@if / else if / else`、`@foreach`、`@{ var x = ... }` | `@switch`、`@while`、LINQ/lambda/方法链 |
| `@{ Layout = "..." }`、`@RenderBody()`、`@section`、`@await RenderSectionAsync` | `Layout = null`（引擎要求字符串，**不声明 Layout 即独立页面**） |
| `@await Html.PartialAsync("Name", model)` | tag helper（`asp-append-version` 等） |

由此带来的改写：

- `@PekHtml.GenerateCssFiles()` / `@T("...")` / `@inject` → 直接写死静态资源路径与中文文案；
- `ViewBag.Title` / `ViewBag.Model` → 统一走 `@Model.*`（控制器组装一个 JSON 模型）；
- 多语言下拉等集合 → `@foreach (var x in Model.languages)`；
- **属性取不到即渲染失败**：Rust 侧在 `Views::render*` 里先用 `with_template_defaults`
  补齐内置模板引用的全部键（`title`/`displayName`/`userName`/`saved`/`languages`/`message`/…），
  宿主只传业务字段也不会 500。

> 注意：Razor 子集隐式表达式等价 .NET `HtmlEncoder.Default`——**非 ASCII 会输出成
> `&#x4FDD;&#x5B58;` 这样的实体**。浏览器显示正常；写测试断言中文时要先还原实体
> （见 `crate::decode_html_entities`，仅 `#[cfg(test)]`）。

## 4. Area 与视图解析

- 路由：`Controller::new("admin/config")` → `/admin/config/{action}`（`dhrust` 支持多段前缀，
  段匹配大小写不敏感）；
- 视图：`Views/{Area}/{Controller}/{Action}.cshtml`，由 `src/views.rs` 拼成
  `Admin/Config/Index` 交给 `ViewRenderer`；
- 共享视图：`Views/Shared/{Name}.cshtml`（`render_shared`）。

## 5. 复用检索证据（写码前）

```powershell
# UEditor：全盘无实现
Get-ChildItem 'G:\Code\Rust' -Recurse -File -Include *.rs |
    Select-String -Pattern 'ueditor|UEditor' -List
# → 无命中

# multipart：只有「待办」与「刻意不用」
Get-ChildItem 'G:\Code\Rust' -Recurse -File -Include *.rs |
    Select-String -Pattern 'form-data|multipart|boundary='
# → dhrust::net::router 模块注释「待办（A2xx 批次…multipart/form-data 解析）」
# → HLZX.EIP doc.rs / docchunk.rs / report.rs「刻意不支持/不走 multipart」
```

结论：UEditor 与 multipart 无既有实现，在本 crate 落地；其余能力（HTTP/路由/控制器/
视图引擎/静态资源/日志/口令/出网客户端/文件名清洗/时间）全部复用 `dhrust` 现成模块。

若之后出现**第二个**需要 `multipart/form-data` 的消费方，按约定把 `src/multipart.rs`
上收进 `dhrust::net`（本 crate 只保留薄壳）。
