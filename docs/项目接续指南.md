- 定位：C# `Pek.DsMallUI`（猿人易 / NCube 后台 UI）的 Rust 实现，crate `pek-dsmallui`（**库**，可被任意 Rust 服务以 path 依赖复用）。
- 参照：`G:\Code\Pek.FrameWork\Pek.DsMallUI`（`PekStartup`、`Controllers/UploadController.cs`、`UEditor/*.cs`、`Areas/Admin/**`）。
- 公共库：`G:\Code\Rust\DH.RustBase`（`dhrust`，features `net` + `razor`）。
- 远程仓库：`https://github.com/RemoteAll/Pek.DsMallUI.git`（remote 名 `origin`，分支 `main`）。
- 根提交：`ac98abb`（2026-11-09）。

## 2. 常用命令

```powershell
cargo check --all-targets                 # 写码期检查
cargo build --example admin_server        # 出示例二进制（dev）
cargo test                                # 单元 + 文档测试（当前 68 项）
cargo clippy --all-targets                # 必须零告警
.\tools\regression.ps1                    # 一键回归：check → test → 示例编译 → 起服务冒烟
cargo run --example admin_server -- 8099  # 手工起服务（默认 8080）
.\tools\sync-wwwroot.ps1                  # 从 C# 工程增量同步第三方静态资源（幂等）
```

- 日常写码用 `cargo check`；要二进制调测用 `cargo build --profile fast`；`--release`/zig 交叉只用于发版。
- 依赖下载走项目内 `.cargo/config.toml`（rsproxy 镜像 + Windows `rust-lld`）。
- 含中文的 `.ps1` 必须 **UTF-8 with BOM**（PS 5.1 按 ANSI 读无 BOM 会直接语法报错）。

## 4. 关键设计约定

| 主题 | 约定 |
|---|---|
| 路由 | `/fileuploader`（C# 绝对路由）、`/Upload/fileuploader`、`/Upload/downloads/{path}`（前缀中间件，因 dhrust 无 `{**path}`）、`/{area}/home|config|login/{action}`（区域默认 `Admin`，可配 `Biz`） |
| 视图 | Area 约定 `Views/{Area}/{Controller}/{Action}.cshtml`（逐段 Pascal、缺失时回退 `Admin`，由 `dhrust` 的 `ViewRenderer::with_fallback_area` 实现）；共享 `Views/Shared/{Name}.cshtml` |
| 模型 | 一律 `serde_json::Value`；`Views::render*` 会补内置模板默认键（缺键即渲染失败） |
| 上传 | `<web_root>/<upload_path>`（默认 `wwwroot/upload`），URL 前缀 `/<upload_path>`；扩展名/体积/路径三重校验 |
| 持久化 | 实现 `AdminBackend`（`settings`/`save_settings`/`login`）；不绑定 ORM |
| 口令 | `dhrust::sign::password`（与 C# `SaltPasswordProvider` 互通） |
| 静态资源 | `DsMallUi::static_files()` → 挂 `Router::fallback`（含 ETag/304）；资源根由 `web_root` 配置（默认 `wwwroot`，业务系统可改任意路径）；默认**磁盘、不编译进二进制**（dhrust `StaticFiles::with_embedded`，空表=纯磁盘）；单文件部署才 `embedded_statics` |
