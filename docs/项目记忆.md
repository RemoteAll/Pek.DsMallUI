### 约定与红线

- 不改 `DH.RustBase`；需要动公共库先问，并连带回归其它消费方。
- 口令只走 `dhrust::sign::password`（与 C# `SaltPasswordProvider` 字节级互通）。
- Razor 子集：禁 `@using/@inject/@helper`、**禁 `Layout = null`**、取不到属性即渲染失败；非 ASCII 输出为 `&#x..;` 实体，测试断言中文先用 `decode_html_entities` 还原。
- 上传三重校验：扩展名白名单 + 体积上限 + 落盘路径必须在根内；抓图只允许 http/https（C# 侧该校验被注释，等于可 SSRF）。
- 静态资源不入库：`wwwroot/` 整目录 gitignore，由脚本同步 / 物化。
- 文档注释须写明与 C# 参考实现的对应关系与差异。

### 实测坑

- `dhrust::net::router` 路径占位只支持单段 `{name}`、无 `{**path}` → 下载走前缀中间件 + `StaticFiles`。
- `dhrust::net::controller::ViewRenderer` 只按 `{Controller}/{Action}` 解析（pascal 仅首字符大写）→ Area 在 `views.rs` 里拼成 `Admin/Config`，未改 dhrust。
- C# 参考实现里 `UploadHandler.Process`、`Crawler.Fetch`、`UeditorConfig.GetStringList` 全是注释状态（上传永远「未知错误」）→ Rust 按 UEditor 官方协议补齐，状态文案逐字一致。
- `{rand:n}`：C# `rand.Next(10^n,10^(n+1))` 实为 n+1 位；Rust 按官方 n 位。
- `ueconfig.json` 的 `imageAllowFiles` 含不带点的 `"webp"` → 比较前统一补点并小写。
- **记忆镜像坑**：`tools/continuity/sync-memory.ps1` 按行首 `## ` 切分章节 → repo 记忆文件内只能用 `###` 及更低级标题，否则镜像会被拆成碎片章节。

### 与 C# 的差异（2026-11-09 复核新增，文档尚未登记）

- **缺省 action**：C# 未带 `action` 走 `NotSupportedHandler`（`action 参数为空或者 action 不被支持。`）；Rust `ueditor_outcome` 未带 action 时按 UEditor 惯例回 **config**。
- **未知 action 文案**：C# `action 参数为空或者 action 不被支持。`；Rust `不支持的操作：{action}`。
- **下载缺失文件**：C# 返回 200 文本 `null`；Rust 返回 `404 Not Found`。
- **能力超集**：C# 的 `uploadvideo`、`listimage`、`listfile` 均在注释里（未启用），Rust 正常实现。
