# Pek.DsMallUI（Rust，2026-11-09 建）

- 路径 `G:\Code\Rust\Pek.DsMallUI`，crate `pek-dsmallui` v0.1.0；参考 C# 工程 `G:\Code\Pek.FrameWork\Pek.DsMallUI`。
- 依赖 `dhrust`（path = `../DH.RustBase`，features `net` + `razor`）；默认 feature `crawler`（启用 `dhrust/http-tls`）。
- 能力：UEditor 后端（config/uploadimage/scrawl/video/file/catchimage/listimage/listfile）、上传下载、
  后台 Area（`/admin/config/*`、`/admin/login/*`）、Razor 子集视图、`StaticFiles` 静态资源。
- 门面：`DsMallUi::builder().web_root().views_root().upload_path().backend().build()`；
  `materialize_defaults()` 物化默认视图 + `ueconfig.json`（只补缺失）；`mount(&mut router)` + `static_files()`。
- 关键事实（坑）
  - `dhrust` **没有** multipart 解析（router 模块注释里是待办）→ 本 crate `src/multipart.rs` 实现；
    出现第二个消费方时应下沉进 `dhrust::net`。
  - Razor 子集**不支持 `Layout = null`**（引擎要求字符串）；不声明 Layout 即独立页面。
  - Razor 子集取**不存在的属性是硬错误** → `Views::render*` 先用 `with_template_defaults` 补齐内置模板用到的键。
  - Razor 子集隐式表达式等价 `HtmlEncoder.Default`：**非 ASCII 输出成 `&#x..;` 实体**（浏览器正常）；
    测试断言中文要先还原（`crate::decode_html_entities`，仅 cfg(test)）。
  - `dhrust::net::router` 路径占位只支持单段 `{name}`（无 `{**path}`）→ 下载用**前缀中间件**
    拦截 `/Upload/downloads/` 再走 `StaticFiles`。
  - `ViewRenderer` 只按 `{Controller}/{Action}` 解析（`pascal` 仅首字符大写），
    Area 约定在本 crate `views.rs` 里把 controller 拼成 `Admin/Config`（未改 dhrust）。
  - C# 参考实现里 `UploadHandler.Process`/`Crawler.Fetch`/`UeditorConfig.GetStringList` 全是注释状态
    （上传永远「未知错误」）→ Rust 侧按 UEditor 官方协议补齐，状态文案保持一致。
  - `{rand:n}`：C# `rand.Next(10^n,10^(n+1))` 是 n+1 位，Rust 按官方生成 n 位。
- 静态资源：C# `wwwroot/static` 825 文件 / 24.6 MB，不入库；`tools/sync-wwwroot.ps1` 增量同步（幂等）。
