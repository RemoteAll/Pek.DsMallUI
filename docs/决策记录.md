# 决策记录

## 2026-11-09 · 新建 `Pek.DsMallUI`（Rust）统一封装

**用户原话**

> 「G:\Code\Pek.FrameWork\Pek.DsMallUI 帮我参考这个项目在G:\Code\Rust目录新建一个类似的目录，
> 这个就是用于统一封装DsMallUI的功能，要结合DH.RustBase一起使用，
> 要使用DH.RustBase中的与C#一样的Controller和Views等web规范」

**决策**

1. **定位**：Rust 侧只封装「可移植的 UI 能力」——UEditor 后端、上传/下载、后台 Area（设置/登录）、
   Razor 子集视图、静态资源服务；不复制 C# 的 XCode 实体与 NuGet 依赖树。
2. **复用优先（检索证据）**：
   - 全盘检索 `ueditor|UEditor`（`G:\Code\Rust`，排除 target）→ **无命中**；
   - 检索 `multipart|form-data|boundary=` → 仅 `dhrust::net::router` 的待办注释与
     HLZX.EIP 三处「刻意不走 multipart」说明 → **无实现可复用**；
   - 因此仅 `multipart` 与新 UEditor 协议在本 crate 落地；HTTP/路由/Controller/Views/StaticFiles/
     日志/口令/出网客户端/文件名清洗/时间全部复用 `dhrust`。
3. **不改公共库**：`dhrust` 的 `ViewRenderer` 只按 `{Controller}/{Action}` 解析；Area 约定在
   本 crate 的 `views.rs` 里拼成 `Admin/Config` 再调用，避免动 `DH.RustBase`（跨仓库改动需另议）。
4. **持久化解耦**：定义 `AdminBackend`（`settings`/`save_settings`/`login`），不绑定 ORM；
   C# 版直接写 `SiteInfo`/`DHSetting`/`SysConfig`，Rust 侧不能照搬。
5. **口令口径**：示例 `MemoryBackend` 使用 `dhrust::sign::password`（与 C# `SaltPasswordProvider`
   字节级互通），符合「登录口令规范」。
6. **静态资源不重复入库**：C# `wwwroot/static` 为 825 文件 / 24.6 MB 第三方资产，
   由 `tools/sync-wwwroot.ps1` 增量同步（实测首次 824 复制 / 二次 824 跳过，幂等）。
7. **视图改写而非照抄**：C# 视图依赖 `@PekHtml.*`/`@T()`/tag helper，Razor 子集不支持；
   改写后仍可被 C# 端渲染（子集是双端合同）。
8. **差异必修**：C# `UploadHandler.Process`、`Crawler.Fetch`、`UeditorConfig.GetStringList`
   均为注释状态（上传永远「未知错误」），Rust 侧按 UEditor 官方协议补齐；
   `{rand:n}` 按官方生成 n 位（C# 实际 n+1 位）。

**验证（实测）**

- `cargo clippy --all-targets`：**零告警**；
- `tools/regression.ps1`：`cargo check` 通过 → `cargo test` **68 项全绿**（65 单元 + 3 文档）
  → 示例编译 → 冒烟 4 项（设置页 200/4865 字节、UEditor 配置、登录失败路径、图片上传 SUCCESS）
  → **PASSED**；
- 手工实测（端口 18081）：登录 302、设置保存后回读命中新值、`/Upload/downloads/**` 返回
  `200 + image/png + ETag + Content-Disposition`、`/ueconfig.json` 200/6628 字节。

## 2026-11-10 · 后台 Area 落地（区域名可配置：默认 Admin，本项目 Biz）

**用户原话**

> 「先帮我结合Pek.DSMallUI将管理后台弄起来，要使用Area的区域，区域名称用Biz，这个区域名称默认是Admin，我的意思是要和C#一样可以在使用的项目动态改这个区域名称」
> 「这个动态配置区域是不是要在DH.RustBase中能支持才对？」
> 「我记得DH.RUstBase本身就有一套实现，只是功能不齐全」

**决策 / 动作**

1. 后台按 Areas 组织：`/{area}/home|config|login/{action}`，视图 `Views/{Area}/{Controller}/{Action}.cshtml`；
   区域名在**装配时**决定（`DsMallUiBuilder::admin_area`，默认 `Admin`），示例用 `Biz`。
2. 区域能力**下沉 DH.RustBase**（用户判断正确）：公共库本就有 `Controller` + `ViewRenderer`，
   只补「逐段 Pascal」与「默认区域回退」，不另起一套；DH 提交 `3932333` 已推送。
3. 本 crate `views.rs` 删除自写的区域解析/回退，改为
   `ViewRenderer::with_root(...).with_fallback_area("Admin")`；只保留内置视图物化与模板默认键。
4. 新增后台首页 `/{area}/home/index`（控制台卡片 + 快捷入口），登录成功落地页改为该页。
5. 默认视图规范位置保持 `Views/Admin/**`；其它区域靠回退复用，定制时在 `Views/{Area}/**` 同名覆盖。

**验证（实测）**

- `cargo test`：**84 项全绿**（79 单元 + 5 文档）；`cargo clippy --all-targets` 零告警；
- 区域 `Biz`：`/biz/home/index` 200、`/biz/config/index` 200、`/biz/login/index` 200、
  `/admin/home/index` 404、登录 302 → `/biz/home/index`、保存设置 200 且回读命中、UEditor 配置 200；
- 区域 `Admin`：`/admin/home/index` 200、`/biz/home/index` 404、登录 302 → `/admin/home/index`；
- DH 连带：`Pek.RCard`、`Pek.RPanlServer` `cargo check` 通过；DH 全量 464 passed（2 ignored）。
